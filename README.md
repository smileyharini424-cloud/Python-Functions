# Python Functions

## Explanation

A function is a reusable block of code designed to perform a specific task. Functions help make programs organized, reusable, and easier to maintain.

A function is defined using the `def` keyword.

## Problem Statement

Write a Python program that defines functions for addition, subtraction, multiplication, and division, and calls them using user-provided numbers.

## Features

* Defines multiple functions
* Calls functions from the main program
* Accepts user input
* Performs arithmetic operations
* Demonstrates code reusability

## How It Works

The program defines four functions:

* `add()` – performs addition
* `subtract()` – performs subtraction
* `multiply()` – performs multiplication
* `divide()` – performs division

The user enters two numbers, and each function is called to perform the corresponding operation.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Define the arithmetic functions.
3. Read two numbers from the user.
4. Call the addition function.
5. Call the subtraction function.
6. Call the multiplication function.
7. Call the division function.
8. Display the results.
9. End the program.

## Sample Input

```text
Enter first number: 20
Enter second number: 5
```

## Sample Output

```text
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4.0
```
